# Fotografías institucionales

Espacio reservado para fotografías institucionales del sitio.

## Requerimientos por foto

- Formato: JPG optimizado o WebP
- Peso máximo: 300 KB por imagen
- Dimensiones recomendadas: 1920x1080 (hero) o 800x600 (interior)
- Metadatos obligatorios:
  - Crédito de autor
  - Fecha de captura
  - Lugar
- Nombre del archivo: `fecha_lugar_descripcion.jpg`
