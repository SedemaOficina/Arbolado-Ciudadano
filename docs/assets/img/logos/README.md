- `sedema.svg` · Logo Secretaría del Medio Ambiente
- `sedema-blanco.svg` · Versión para fondos oscuros
- `cdmx.svg` · Escudo Ciudad de México
- `cdmx-blanco.svg` · Versión para fondos oscuros

## Uso

Los logotipos son propiedad del Gobierno de la Ciudad de México. Su uso debe seguir el Manual de Identidad Gráfica GCDMX.

Solicitar autorización de uso a: autorizacionimagen@cdmx.gob.mx
