# Datos del sitio

## Archivos requeridos

### alcaldias.geojson
Perímetro oficial de las 16 alcaldías de la Ciudad de México.
Fuente: Portal de Datos Abiertos CDMX
Formato: GeoJSON FeatureCollection
Uso: overlay del mapa institucional

### normativa.json (opcional futuro)
Estructura navegable del marco normativo aplicable.

## Actualización

Los datos se actualizan cuando cambien las fuentes oficiales. Documentar la actualización en `CHANGELOG.md`.
