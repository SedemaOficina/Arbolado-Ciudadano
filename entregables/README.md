# Documentos Institucionales

Notas informativas, oficios, presentaciones y documentos institucionales asociados al proyecto Micrositio de Arbolado Urbano.

## Estructura

- `notas-informativas/` · Notas para titulares con membrete SEDEMA
- `oficios/` · Oficios institucionales
- `presentaciones/` · Presentaciones ejecutivas

## Convención de nombres

`YYYY-MM-DD_tipo_asunto-breve.docx`

Ejemplos:
- `2026-08-20_nota_avance-micrositio-v21.docx`
- `2026-08-25_oficio_solicitud-autorizacion-identidad-grafica.docx`
- `2026-09-01_presentacion_micrositio-para-titular.pptx`
